# render-light-shaft

室内场景加体积光柱，结果光线穿过墙、地面还糊出一片光斑：阴影图深度比较把与遮挡体同深度的表面判成遮挡，自遮挡边缘发黑；阴影采样不加常量 bias，斜面上出现条纹；采样抖动幅度按整步缩放，样本冲出当前步和积分区间；光线积分不做透射衰减，远处散射过亮、能量不守恒；遮挡样本仍被累加散射，光柱直接穿墙；Henyey-Greenstein 相位的 g 未钳制到 (−1,1)，g=1 时除零；每像素抖动复用同一 seed，条带没有被消除；能量检查累加 RGB 分量而不按归一化透射率计算，结果大于 1；批量积分复用同一条光线的采样位置，光线之间互相串扰；校验函数不检查 UV 是否落在 [0,1]，越界采样无人拦截；shaft/march.py 是核心，tests/test_march.py 15个红。要修的是：上述 10 个隐蔽缺陷，8 个桩函数全部变为正确实现。

## 运行方式

在仓库根目录执行：

```powershell
python -m pytest tests -q
```

初始输出应恰好为 `15 failed`，且不能出现 collection、import 或 syntax error。测试只依赖 Python 3 标准库与 pytest，不需要联网，也不使用随机数。
